# Spotty para el evaluador del curso

Paquete del avance REDALE con los requerimientos corregidos durante la revisión.

- `requerimientos/`: enunciado original y sección R del avance actual.
- `users/`: alumno y docente, extraídos de los roles e interacciones del avance.
- `Listado_Diagramas/`: ocho láminas PNG originales y las secciones de diseño, datos, componentes y escalamiento del avance.

Los diagramas conservan el borrador visual del 22 de octubre; no se han actualizado para reflejar las últimas precisiones del plazo de notas. La imagen principal es `Listado_Diagramas/Diagrama Final.png`.

Repositorio previsto: `LuisMUtec/SWA-Labs`, rama `lab11/spotty-evaluacion`, carpeta `LAB11-Spotty`. El evaluador recibe `path: "LAB11-Spotty"` y los nombres relativos `requerimientos`, `users` y `Listado_Diagramas`. La imagen principal se llama `Diagrama Final.png`, como exige el servicio. La evaluación debe registrar el commit exacto enviado.
