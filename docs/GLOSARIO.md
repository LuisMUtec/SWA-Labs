# Glosario

| Término | Significado en RemoteSchooly |
|---|---|
| Paquete semanal | Versión inmutable de todos los recursos obligatorios para un curso, audiencia y semana |
| Manifiesto | Inventario del paquete: identidad, tamaño, versión y huella de cada recurso |
| Recurso | Archivo o contenido individual incluido en un paquete |
| Sede | Escuela remota con un nodo local y conectividad intermitente |
| Nodo local | Equipo administrado en la sede que sincroniza y sirve contenido por la red local |
| `Listo` | Paquete cuyo manifiesto y recursos obligatorios fueron verificados para la misma versión |
| `Incompleto` | Paquete parcial, corrupto o sin algún recurso obligatorio; no puede abrirse como semana vigente |
| Unidad aprobada | Fragmento pedagógico aceptado por un Profesor de Lima bajo la rúbrica común |
| Línea base | Consumo versionado de IA sobre tareas y fuentes fijas antes de optimizar |
| Token reutilizado | Consumo evitado porque se reutilizó contenido aprobado sin llamar al proveedor de IA |
| Telemetría vencida | Último reporte de una sede más antiguo que el umbral configurado; no equivale a error confirmado |
| Bandeja local | Avances o eventos pendientes de confirmación por el centro |
